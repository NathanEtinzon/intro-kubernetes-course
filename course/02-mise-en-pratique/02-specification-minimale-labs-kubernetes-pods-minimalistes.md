# Spécification minimale – labs Kubernetes (pods minimalistes)

#### Matériel

-

**CPU** : 2 vCPU

-

**Mémoire** : 4 Go RAM

-

**Stockage** : 20 Go libres (SSD recommandé)

#### Logiciel

-

**Linux** (Ubuntu 22.04+, Debian 12+..)

-

**k3s** ≥ v1.28.x

-

**kubectl** (même version mineure que le cluster)

-

**Runtime conteneur** : containerd (fourni avec k3s)

-

**Éditeur de texte** (nano, vim ou équivalent)
