# Importer le cours dans Moodle

Le fichier principal du cours est :

```text
moodle/intro-kubernetes-course.mbz
```

Ce fichier est une sauvegarde Moodle restaurable dans une instance Moodle compatible.

## Procédure

1. Télécharger le fichier `.mbz` depuis le dossier `moodle/` ou depuis la GitHub Release `v1.0.0`.
2. Se connecter à Moodle avec un compte autorisé à restaurer des cours.
3. Créer un nouveau cours ou ouvrir le cours cible.
4. Accéder à la fonction de restauration de cours.
5. Importer `intro-kubernetes-course.mbz`.
6. Suivre l'assistant de restauration et contrôler les options proposées.
7. Lancer la restauration.
8. Vérifier les sections, activités, ressources, quiz, liens et captures d'écran.

## Contrôles après import

Après restauration, vérifier que les contenus sont accessibles aux rôles attendus, que les médias s'affichent correctement, que les quiz ou activités d'évaluation sont présents, et qu'aucune donnée personnelle ou information interne non destinée aux apprenants n'a été restaurée.
